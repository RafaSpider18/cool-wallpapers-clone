# T-018 — Rutas `/tag/[tag]` (SEO long-tail)

**Estado:** done · **Dueño:** supervisor · **Abierta:** 2026-10-28

## Objetivo
Páginas estáticas por tag (`/tag/night`, `/tag/space`...) que listan todos los
wallpapers con ese tag, reusando el navegador paginado existente.

## Alcance
- `app/tag/[tag]/page.tsx` con `generateStaticParams` (tags con ≥2 wallpapers).
- Metadata con canonical/metas derivadas del tag; integrado en `app/sitemap.ts`.
- Migas: Inicio → Tags → Tag.
- Página índice `/tags` con enlaces a cada tag (hub interno).

## Fuera de alcance
- Rediseño del grid/paginación (reusa `CategoryBrowser`).

## Verificación
1. `npm run build` (rutas `/tag/*` como SSG) + `npm run test:e2e`.
2. Sitemap contiene las URLs de tags.

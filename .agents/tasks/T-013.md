# T-013 — Arte raster propio (thumbs + full 1080p/4K JPEG)

**Estado:** done · **Dueño:** supervisor · **Abierta:** 2026-10-28

## Objetivo
Sustituir el arte SVG de demo (degradado plano) por imágenes raster generadas
proceduralmente con Playwright/Chromium, una escena distinta por categoría y
variantes nominales 1080p y 4K. Sin descargar nada de sitios externos (ADR-4).

## Alcance
- `scripts/gen-assets.mjs`: motor de escenas (aurora, orb, ridges, citygrid,
  bloom, streaks, mono) + pipeline de render JPEG (thumb 640×360, full 1920×1080
  y 3840×2160) sobre Chromium headless; regenera `data/wallpapers.json`.
- Baja la variante 8K: el arte pasa a JPEG y 8K dispara el peso del repo sin
  beneficio demo (queda ADR-8 actualizado).
- `data/collections.json`: thumbs `.svg` → `.jpg`.
- `public/walls/{full,thumbs}`: se eliminan los SVG antiguos; entran los JPEG.
- Tests E2E: el caso de resoluciones pasa de 8K a flujo 1080p/4K JPEG.

## Fuera de alcance
- Cambios de layout, rutas o paginación.
- Ampliar el catálogo de 60 items (otra tarea).

## Verificación
1. `npm run gen:assets` genera 60 thumbs + 60 full 1080p + 60 full 4K (180 JPEG).
2. `npm run build`, `npm run lint`, `npx tsc --noEmit`.
3. `npm run test:e2e` 13/13.
4. Lighthouse desktop en listado y detalle se mantiene ≥ 100/100 y sin CLS.

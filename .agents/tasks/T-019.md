# T-019 — Catálogo ampliado: fotografía real con licencia libre

**Estado:** done · **Dueño:** supervisor · **Abierta:** 2026-10-28

## Objetivo
Ampliar el catálogo con fotografía **real** curada de Wikimedia Commons
(licencias abiertas CC0/PD/CC-BY(-SA)) en categorías donde la foto aporta
(espacio, naturaleza, ciudades, comida...). Mantener los 60 items generativos.

## Restricciones duras
- **Prohibido** descargar assets de 4kwallpapers.com (ADR-4). Solo fuentes de
  licencia abierta verificables (Commons API con extmetadata).
- Cada foto guarda `credit` (autor, licencia, URL origen) en `data/photos.json`
  y se muestra en la ficha del wallpaper.

## Alcance
- Script `scripts/process-photos.mjs`: descarga originales suficientemente
  grandes, recorte 16:9 centro y render thumb/1080p/4K JPEG (pipeline Chromium
  T-013), escribe `data/photos.json`.
- `lib/wallpapers.ts` concatena wallpapers + photos; tipo `Wallpaper` gana
  `credit?`.
- Ficha del detalle muestra créditos/licencia; página `/credits` (también en
  footer) lista todas las atribuciones.

## Fuera de alcance
- Cambiar el arte generativo existente.

## Verificación
1. `npm run gen:assets` + `npm run process:photos` sin errores.
2. `npm run build` + `npm run test:e2e` (nuevo caso: ficha con crédito).
3. Sitemap incluye los nuevos items.

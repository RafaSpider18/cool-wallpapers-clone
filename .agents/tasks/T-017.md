# T-017 — `noindex` en `/search`

**Estado:** done · **Dueño:** supervisor · **Abierta:** 2026-10-28

## Objetivo
Evitar que los buscadores indexen páginas de búsqueda (URL con parámetro `?q=`),
que duplican contenido y diluyen el SEO del listado.

## Alcance
- `app/search/page.tsx`: `robots: { index: false, follow: true }` vía metadata.
- `/robots.txt` ya excluye `/search` (T-015); esto refuerza el caso de enlaces entrantes.

## Verificación
1. `npx tsc --noEmit` + `npm run build`.
2. `GET /search` HTML contiene `name="robots" content="noindex,follow"` (o equivalente).

  y el servidor siempre pre-renderiza página 1 (HTML con `<title>`/`<meta
  description>` dentro del `<head>`).

  para el listado de cada categoría. Categorías desconocidas siguen cayendo en

  paginador: estado local + `router.replace`.

  post-hidratación cuando la URL trae `?page=2`.
- Documentación: `docs/qa-report.md` (defecto #5, tabla Lighthouse con las 4
  categorías, límites) y `docs/plan.md` (fase 13).

- [ ] Informe de métricas en `docs/qa-report.md` (no en `MEMORIA.md`, por ADR-6)

## Verificación
`npm run test:e2e`

## Notas del supervisor
- Instala solo lo necesario: `npm i -D @playwright/test` y `npx playwright install chromium`.
- `playwright.config.ts`: `webServer: { command: "npm run start", url: "http://localhost:3000", reuseExistingServer: true, timeout: 120000 }`. Ejecuta `npm run build` antes de la suite (el server de producción necesita `.next`).
- Casos mínimos (uno por ruta):
  1. `/` redirige a `/cool-wallpapers` (comprueba `page.url()`).
  2. `/cool-wallpapers` pinta 12 cards y muestra paginación.
  3. `?page=2` cambia el primer card respecto a la página 1.
  4. `/abstract` solo contiene items de abstract.
  5. Detalle `/abstract/aurora-veil-1.html`: H1, tags y un `<a download>` con `href` que empieza por `/walls/full/`.
  6. `/search?q=anime` muestra contador > 0; `/search?q=zzzz` muestra el estado vacío.
  7. `/random` responde 307: usa `request.get("/random", { maxRedirects: 0 })` y comprueba `status()` y `headers().location`.
- Lighthouse: `npx lighthouse http://localhost:3000/cool-wallpapers --preset=desktop --only-categories=performance,accessibility --chrome-flags="--headless=new" --output=json --output-path=docs/lighthouse.json`. Si Lighthouse no puede arrancar Chrome en este entorno, no lo maquilles: documenta el bloqueo en `docs/qa-report.md` y reporta `blocked` con el motivo.
- Añade `"test:e2e": "playwright test"` a `package.json`.
